MOSAIC: A Multimodal Edge-AI SoC

Lead Researcher BRAC University, Dhaka Aug 2026 – Present AMD Artix-7 XC7A200T

Overview

Continuous monitoring of respiratory symptoms, such as counting coughs in chronic disease, has to run on a wearable: low power, predictable latency and no cloud. Typical accelerators either hard-wire one network into logic with no processor, or keep weights in external DRAM and need many multipliers. MOSAIC set out to be a complete, host-integrated, DRAM-free and bit-exact SoC on a mid-size FPGA.

A two-branch network fuses an audio temporal-convolutional network (on MFCC features) with a 1-D CNN on the motion signal. The network is compressed so that its widest layers use ternary weights {−1, 0, +1} and the rest use 4-bit integers. It is compiled to hardware with Vitis HLS, all 90 KiB of weights sit in on-chip ROM, and a small RISC-V processor runs the system. The whole 15.2-million-MAC network runs on 9 hardware multipliers and stays within 0.08 percentage points of the floating-point accuracy.

Architecture

The RISC-V core is the only external interface. It boots from the SD card, copies each input window into the accelerator over memory-mapped I/O, starts the network and reports the result over UART. Inside the accelerator, a layer sequencer sends each layer to the ternary engine, the int4 engine or an auxiliary kernel, all sharing one adder tree, accumulator and rescale path.

Network28 layers, 238,400 weights, 15.2 M MAC per inference
Precision7 layers ternary (178,176 weights), 10 layers int4
Datapath16-lane MAC, 99.2% lane utilization, shift-only requantization
HostRV32I + Zicsr multi-cycle core (1,791 LUTs): SD-card boot, input feed, UART report
Clock100 MHz, single clock domain

Accuracy against fan-in budget

Training limits how many inputs (taps) each ternary neuron may use. Keeping all 64 taps holds accuracy at 93.08%; cutting the budget to 32 or 24 taps costs 9 to 16 points.

Verification

The synthesized SoC is bit-exact to the reference integer model: six independent checks give the same class, logits and per-layer checksums, and an independent review refuted none of them.

Compression Study

Before the hardware, the branch-aware mixed-precision quantization was tested on three multimodal datasets with different encoders and fusion methods, to see whether a method first shown on image networks carries over.

DatasetTaskEncoders + fusionFloat → compressed
EPFL CoughCough vs non-coughTCN + CNN, concatenation94.32% → 93.16%
MHEALTH12 activitiesCNN + CNN, compact bilinear87.60% → 90.11%
NonastredaTool-wear stateSpiking CNN ×2 + LSTM, multiplication65.14% → 60.07%

On MHEALTH the compressed network beats the floating-point one. On Nonastreda, quantized LSTM branches collapsed to 0% in 8 of 10 folds; the cause was traced to NaN propagation through global gradient clipping and stale optimizer state, and a weight-normalization fix brought collapses to 0 of 10 with about 9× faster training.
